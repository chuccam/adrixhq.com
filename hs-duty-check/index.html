HS Duty Check · for Shopify

Wrong HS codes cost you at the border.

Since the US ended de minimis, every parcel needs a proper HS code. Shopify uses your codes to estimate duties at checkout, and you pay the difference when the estimate is off. HS Duty Check finds the gaps and helps you close them.

Scan

Minutes, not a customs audit.

Install the app and it sorts every product into one of four groups.

no code

Missing HS code

These products ship with no classification at all.

partial

Generic code, no US detail

US duty rates live at the 8-digit level. A 6-digit code is where under-collection hides.

retired

Code no longer in the HTS

The US tariff schedule is revised several times a year. Old codes stop being valid.

valid

Valid 10-digit code

Good to go. We keep watching for HTS revisions that affect it.

Fix

Then fix them, on your terms.

  1. Get a cited suggestion

    Each product gets a 10-digit US HTS code, quoted word for word from the official schedule so you can check it.

  2. Review and approve

    Nothing is written to Shopify until you approve it. Approve one by one, in bulk, or by group.

  3. Keep a full history

    See every change: old code, new code, who approved it and when. Restore any previous code in one click.

  4. Reconcile real duties

    Upload your carrier or Shopify duty bills as CSV and see, order by order, where what you collected differs from what you paid.

  5. Stay current

    When an HTS revision changes or removes a code you use, the app tells you.
